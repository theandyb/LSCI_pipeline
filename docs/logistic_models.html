Introduction

Here in this document we’ll explore one particular alternative model structure for the examination of the influence of local sequence context on rates of germline mutation: logistic regression models. But first, some functions to enable loading of data “on the fly”:

Data Functions

#' Load counts of singletons and controls stratified by nucleotides at given flanking positions
#' @param subtype mutation subtype
#' @param population 1kGP super population (ALL for all all five)
#' @param rel_values vector of relative positions to stratify singleton and control counts by
motif_df <- function(subtype, population, rel_vals = c(-1:1)){
  rel_vals <- sort(rel_vals)
  df <- try(get_motif_table(subtype, population, "output", rel_vals = as.integer(rel_vals)))
  if (inherits(df, 'try-error')){
    py_eval('ray.shutdown()')
  }
  return(df)
}

#' Function to start underlying ray instance
#' If not run before motif_df, an instance using all cores will be started, which might not be desirable
ray_start <- function(){
  py_eval('ray.init(num_cpus=22)')
}

#' Function to stop underlying ray instance
#' Not sure what happens if this isn't run when R session stops ¯\_(ツ)_/¯
ray_shutdown <- function(){
  py_eval('ray.shutdown()')
}

Single Position Effects

For our first example, let’s compare the results of two models for the influence of the nucleotide at the -1 relative position for the A > G mutation subtype.

Model 1:

\[ \textrm{logit}(\Pr(X_i \textrm{singleton} | \textrm{nucleotide}_i)) = \beta_0 + \sum_{j \in C,G,T} \beta_j I(\textrm{nucleotide}_i = j) \]

And model 2:

\[ \log(n_i^s) = \lambda_0 + \lambda_{\textrm{singleton}}I(s=\textrm{singleton}) + \sum_{j \in C,G,T} \lambda_j I(i=j) \]

Both models are for data which we can represent in the following table:
